# CodeAlpha_CreditScoringModel
Credit Scoring Model - CodeAlpha Machine Learning Internship


This project predicts the creditworthiness of an individual using
financial information.

## Features

- Income
- Debt
- Payment History

## Machine Learning Algorithm

Logistic Regression

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Project Objective

The objective of this project is to predict whether an individual
is creditworthy based on their financial history.

# Credit Scoring Model

## CodeAlpha Machine Learning Internship

This project predicts the creditworthiness of individuals using the German Credit dataset and a Logistic Regression machine learning model.

## Objective

The objective of this project is to predict whether a customer has good or bad credit risk based on their financial and personal information.

## Dataset

The project uses the **German Credit dataset** containing:

* 1000 records
* 20 input features
* Credit risk as the target variable

## Machine Learning Approach

1. Load the dataset
2. Preprocess the data
3. Encode categorical features using One-Hot Encoding
4. Split the data into training and testing sets
5. Train a Logistic Regression model
6. Make predictions
7. Evaluate the model

## Evaluation Results

| Metric    |  Score |
| --------- | -----: |
| Accuracy  | 71.50% |
| Precision | 78.23% |
| Recall    | 82.14% |
| F1 Score  | 80.14% |
| ROC-AUC   | 75.61% |
